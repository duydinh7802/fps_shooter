
# FPS Shooter

A 3D Top-down / Isometric Shooter game
developed using Godot Engine 4.x and GDScript.

## Tech Stack

- Godot Engine 4.x
- GDScript
- Git

## Project Structure

- assets/: Game assets
- scenes/: Godot scenes
- scripts/: Game logic
- resources/: Reusable game data
- addons/: Godot plugins
- docs/: Project documentation

## Getting Started

1. Install Godot Engine 4.x Standard.
2. Clone this repository.
3. Open project.godot using Godot Project Manager.
4. Run the main scene.

## Development

The project follows a milestone-based development
